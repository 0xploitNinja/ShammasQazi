> ls portfolio/

Exploring offensive security, defensive operations, application security, AI security, cloud infrastructure, and security automation through practical engineering, research, and continuous learning.

Application Security & Secure Code Review

Performing application security assessments, manual source code reviews, and secure design evaluations to identify vulnerabilities, insecure coding patterns, authentication and authorization weaknesses, and business logic flaws. Supporting remediation through developer collaboration, security requirements, and OWASP-aligned practices.

Web Application & API Penetration Testing

Assessing web applications and APIs for authentication weaknesses, authorization bypasses, injection flaws, SSRF, XXE, XSS, business logic vulnerabilities, and insecure configurations.

Active Directory & Infrastructure Penetration Testing

Assessing Active Directory and network environments through enumeration, privilege escalation, ACL abuse, Kerberos attacks, credential exposure, lateral movement, and attack path analysis.

AI Agent Security & LLM Security

Assessing security risks in AI-powered applications and autonomous agent workflows, including prompt injection, tool misuse, excessive agency, sensitive information exposure, insecure integrations, and trust boundary violations. Exploring adversarial testing and security controls for LLM-based systems and AI agents.

Red Teaming & Purple Teaming

Developing adversary simulation capabilities through attack chain development, offensive techniques, and realistic security exercises, while validating detection coverage and strengthening defensive controls.

CI/CD Security & DevSecOps

Building expertise in securing software delivery pipelines through automated security testing, SAST, DAST, dependency scanning, secret detection, container image scanning, and secure deployment practices.

Cloud, Kubernetes & Container Security

Expanding into cloud-native security, including cloud IAM, infrastructure misconfigurations, container security, Kubernetes hardening, workload protection, and secure cloud architecture.

SOC, SIEM Engineering & Incident Response

Engineering security monitoring through custom detections, log correlation, alert tuning, and SIEM workflows, while investigating security events, analyzing evidence, and coordinating incident containment and remediation.

Security Automation & Tool Development

Building Python-based security tools, scripts, and repeatable workflows to improve vulnerability management, detection engineering, security reporting, incident investigation, and operational efficiency.

Security Engineering & Infrastructure Hardening

Strengthening applications, endpoints, operating systems, databases, and network infrastructure through secure configurations, vulnerability management, security baselines, architecture reviews, and control validation.
